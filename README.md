# CTF Writeups – Binary Exploitation & Security Challenges

This repository contains writeups for various cybersecurity challenges I solved as part of my personal training in offensive security.

These challenges focus mainly on:

- Binary exploitation (buffer overflow, ROP, format string, etc.)
- Reverse engineering
- Fuzzing and vulnerability discovery
- Low-level debugging and memory analysis

The goal is to improve my skills in vulnerability research, exploit development, and secure software analysis.

---

## Skills demonstrated

- Static analysis (Ghidra, IDA, objdump)
- Dynamic analysis (GDB, pwndbg, strace)
- Exploit development using Python and pwntools
- Memory corruption exploitation
- Understanding of Linux process memory layout
- Debugging and root cause analysis
